# StoryNav

## Overview

Fixed top navigation bar with chapter links, a pre-order call-to-action button, and a bottom timeline bar that fills smoothly as the page scrolls.

## Examples

### Basic Usage

```tsx
<StoryNav />
```

## API Reference

| Parameter | Type | Default | Required | Description |
|---|---|---|---|---|
| - | - | - | - | No configurable props; reads target sections by ID. |

## Dependencies

None.
