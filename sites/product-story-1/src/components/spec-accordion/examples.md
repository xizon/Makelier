# SpecAccordion

## Overview

Expandable accordion list for technical specifications and pre-order FAQs. One item is open at a time; opening one closes the others with smooth grid-row transitions and a rotating `+` icon.

## Examples

### Basic Usage

```tsx
<SpecAccordion />
```
