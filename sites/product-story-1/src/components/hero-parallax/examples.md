# HeroParallax

## Overview

Full-bleed hero section with a looping typewriter subtitle, a featured skateboard deck graphic, and multi-layer parallax terrain silhouettes that mask the deck as you scroll.

## Examples

### Basic Usage

```tsx
<HeroParallax />
```

## API Reference

| Parameter | Type | Default | Required | Description |
|---|---|---|---|---|
| - | - | - | - | No configurable props; reads typewriter phrases from `data-phrases`. |

## Dependencies

None.
