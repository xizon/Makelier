# MetricsCounter

## Overview

Telemetry grid that animates numeric counters upward with a scale bounce and expands progress bars once the section enters the viewport.

## Examples

### Basic Usage

```tsx
<MetricsCounter />
```

## API Reference

| Parameter | Type | Default | Required | Description |
|---|---|---|---|---|
| - | - | - | - | No configurable props; reads targets from `data-target` and `data-decimals`. |

## Dependencies

- [gsap](https://gsap.com/) - `^3.15.1`
